# CLAUDE.md

Этот файл нужен, чтобы Claude Code при работе **над самим оркестратором** подхватывал
проектные правила. Содержание не дублируется — оно живёт в `AGENTS.md` и импортируется ниже.

@AGENTS.md

> Примечание об изоляции: при прогонах оркестратор запускает headless-Claude в каталоге
> workspace с флагом `--bare` (см. `orchestrator/agents/claude_code.py`), поэтому этот
> `CLAUDE.md` НЕ протекает во вложенные workspace-проекты. Отключается через `--claude-no-bare`.
